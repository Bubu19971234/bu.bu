# Come pubblicare
Shopify Admin → Impostazioni → Policy. Per ogni policy: apri l'editor, clicca l'icona "<>" (mostra HTML), cancella tutto, incolla il file e salva.
- Contatti → 1-contatti.html
- Spedizioni → 2-spedizioni.html
- Rimborsi → 3-resi-rimborsi.html
- Termini e condizioni del servizio → 4-termini.html
- Informativa legale → 5-note-legali.html
- Privacy → 6-privacy-correzioni.md (sono solo correzioni puntuali)

Footer: Negozio online → Temi → Personalizza → sezione Footer → blocco Menu → scegli "Footer legale" (il menu è già creato).
